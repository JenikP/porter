# Phase 6 — integrations

Status: PARTIAL. Working gateway boundaries and simulators; no external vendor account claimed live.

Implemented configured HTTP or simulator route estimation; address suggestion boundary; authorization/capture/refund/void/payout boundaries; stable idempotency keys and rollback on provider failure; HMAC-verified payment confirmation endpoint with durable event IDs. Existing domain dispute holds and weekly payout ledger are retained. In-app delivery notifications persist. Optional email/SMS/push notifications use a durable outbox, gateway key, retry backoff and terminal FAILED status; simulator deliveries are explicitly SIMULATED. Recovery delivery refuses simulator use in production. Authenticated native device registration is account-owned and cleared on logout. Driver foreground location is stored centrally and filtered to the relevant customer. Production startup requires configured gateways unless staging explicitly allows simulators.

Verification: local HTTP fixtures exercise real outbound requests for routes/recovery and authorize/capture/refund/cancellation-fee/void/payout plus EMAIL/SMS/PUSH contracts. Unavailable gateways reject requests; bearer and stable operation keys are asserted. Production-browser scenario tests valid and forged webhook signatures, repeated confirmation without double credit, simulated outbox rows, account-scoped foreground coordinates, payment/refund/payout persistence and no duplicate payout processing. All compile/build/domain/provider/browser checks pass locally.

Limitations: gateway contracts require provider-specific implementations and credentials; a generic HTTP fixture is not a live integration. Real payment tokenization/checkout, merchant/driver onboarding, settlement and ambiguous-result reconciliation are not implemented/verified. Webhooks confirm already-initiated domain actions, not arbitrary external settlement. Outbound gateway must honor idempotency keys; queues lack operator requeue/dead-letter tooling. Routing provider must validate geographic scope and addresses. No APNs/FCM/SMS/mail account, live map or background GPS has been tested. External provisioning is required to complete this phase.
